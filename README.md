## 🌟 核心特色与理念

### 1. 严格字数预算与大道至简
- **单页字数上限**：每页核心文案控制在 **≤ 35–50 字**，避免大段文字堆砌。
- **3 秒一览原则**：观众视线落在画面的前 3 秒内，能够无压力看清核心主结论，无需费力阅读。
- **合理舒适留白**：留白让核心内容自然浮现。保持舒适开阔的空间比例，不为了“充实”而堆叠多余装饰。

### 2. 内容驱动排版 (Content-Driven Layout)
- **从核心命题推导排版**：不机械复用死板的四格或六格卡片，构图由内容本质推导演化。
- **清晰直观的图表语言**：大号数字对比排版、生理节奏波形、自底向上阶梯模型、同心圆层级与闭环流程图。

### 3. 实用的交互演示功能
- **16:9 等比居中缩放**：原生 JS Transform 监听窗口缩放，全屏无黑边、无排版畸变。
- **全屏沉浸放映 (True Fullscreen)**：调用原生 Fullscreen API，全屏自动隐去翻页按钮，底部悬浮极简指示器，支持键盘左右键盲操翻页。
- **一键导出 HTML (Clean HTML Export)**：将当前所有文案修改与配色直接改写进静态源码中，移除多余控制条，生成零依赖独立单文件，在任何电脑和投影仪上离线双击即用。
- **原生 16:9 多页矢量 PDF 导出**：支持浏览器快捷键 `P` (`window.print()`) 与 Headless 自动化导出，连续无缝输出全部页面，无任何裁切与白边。
- **多款传统配色与对比度适配**：内置传统配色方案，深浅背景自动反转高光与标注，确保清晰阅读。
- **行内所见即所得文案编辑 (Inline Editing)**：按 `E` 键即可直接编辑任意文字，按 `Cmd+S` 实时保存至本地。

## ⌨️ 快捷键速查

| 快捷键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **`→` / `Space` / `PageDown`** | 下一页 | 平滑切换，自动运行进场动效 |
| **`←` / `PageUp`** | 上一页 | 返回上一页 |
| **`F`** | **全屏放映** | 原生全屏放映，自动隐去控制按钮，底部悬浮极简指示器 |
| **`E`** | **编辑文案** | 开启 / 退出行内文字编辑模式 |
| **`Cmd + S` / `Ctrl + S`** | 保存文案 | 将修改后的文案保存至本地 |
| **`P`** | **导出 PDF** | 严格 16:9 输出全部幻灯片 |
| **`R`** | 重播动效 | 重新播放当前页进场动画 |
| **`Esc`** | 退出全屏 | 退出全屏放映或取消编辑 |

## 🚀 快速开始

### 1. 直接本地体验
无需安装任何复杂编译环境或后台，直接用任意现代浏览器打开以下文件即可：
- 双风格体验：`showcases/editing_principles/demo_showcase.html`
- 档案版：`showcases/editing_principles/editing_principles_artisan.html`
- 简洁版：`showcases/editing_principles/editing_principles_editorial.html`

### 2. 导出演示文件
1. 在浏览器打开任意页面，按 `E` 编辑修改文字，在“配色”抽屉选择喜爱的颜色。
2. 点击右上角或抽屉内的 **“导出 HTML”**。
3. 即可下载完全独立、无控制台的 HTML 文件，拷贝至任何设备均可直接放映！

### 3. 使用命令行自动化导出 PDF
```bash
# 安装 puppeteer
npm install puppeteer

# 导出 Artisan 版 16:9 PDF
node scripts/export_pdf.js showcases/editing_principles/editing_principles_artisan.html my_deck.pdf
```
