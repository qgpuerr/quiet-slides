# Quiet Slides 设计规范与排印美学哲学

> **"大道至简，言有尽而意无穷。"**
> Quiet Slides 拒绝花哨模版与堆砌信息，以克制的内容排版、明确的字数预算与轻量交互，提供清爽自然的数字化演示体验。

---

## 核心排版原则 (The Core Principles)

### 1. 严格字数预算 (Strict Word Budget)
- **单页字数上限**：单屏核心文本总字数控制在 **≤ 35–50 字**，避免长篇累牍。
- **三秒一览法则 (3-Second Rule)**：观众视线落在画面的前 3 秒内，能够无压力看清核心主结论，而非被迫在台下阅读文字。
- **舒适留白 (Negative Space as Breathing Room)**：留白让核心内容自然浮现。宁可保持开阔空间，也不为了“充实”而塞入无意义的色块或修饰点。

### 2. 内容驱动排版 (Content-Driven Layout)
- **拒绝机械套用卡片模版**。每一页的构图结构从当前要表达的命题或数据逻辑本身推导：
  - **对比关系**：采用大号数字与比例条清晰对比（如 51% 核心权重 vs 49% 总和）。
  - **节律与时间**：采用平直的时间波形轴与清晰标注。
  - **优先级与递进**：采用自底向上的阶梯结构。
  - **层级与闭环**：采用嵌套同心圆或流转关系图。

### 3. 动态母色对比度自适应 (Dynamic Contrast Inversion)
- **拒绝同色系隐形事故**：当背景切换至深色母色（如陶土红棕、雪松深墨等）时，次级数据标注、百分比、图表线框**严禁**使用相近的红棕色或暗色。
- **自动反转映射**：
  - 浅色底（如白茶冷灰、羊皮暖纸、浅灰鼠草）：文字为沉静墨黑，高亮使用朱砂印章红或焦茶。
  - 深色/彩色底（如陶土红棕）：文字与标注必须自适应反转为暖乳白（`#FFF8F2`）、淡米金（`#EADBC8`）或高明度灰白，确保在投影仪和低亮度屏幕上达到 **WCAG AAA** 级可读性。

### 4. 严禁倾斜装饰徽章与廉价虚线
- 徽章、微标与元数据必须平直整齐地锚定在发丝基线或角落，禁止使用斜挂 45° 的倾斜贴纸，避免廉价卡通感。
- 引导线统一使用 `0.5px - 1px` 实线或极细发丝线（`opacity: 0.25 - 0.4`），杜绝杂乱的大点虚线干扰视线。

## 双生美学风格体系 (Dual Aesthetic Systems)

| 维度 | Style A · 物料档案版 (Artisan Paper) | Style B · 静奢编辑版 (Minimal Editorial) |
| :--- | :--- | :--- |
| **纸张质感** | 400gsm 纯棉纸微距纤维、压印封签、工作台手稿感 | 现代奢华平滑暖纸、极简克制、呼吸感空间 |
| **排版骨架** | 电影工作台排印、28:72 极端非对称、物理标尺 | 0.5px 极细发丝网格、微距十字准线、巨号衬线大字 |
| **主标题字系** | Playfair Display / Noto Serif SC | Playfair Display Light / Cinzel / 思源宋体 |
| **元数据字系** | Courier Prime 打字机等宽体 | JetBrains Mono / Jost 现代冷感西文 |
| **图表语言** | 脉冲生理波形、阶梯断层、物理图章徽标 | 嵌套同心分级圆、闭环因果图、三列极细线框对比 |
| **推荐适用** | 深度演讲、设计复盘、电影/文学/艺术典藏解析 | 商业创投、品牌发布会、高端产品发布、学术极简汇报 |
