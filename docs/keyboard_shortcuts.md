# Quiet Slides 交互控制与快捷键指南

Quiet Slides 内置自研 16:9 等比缩放引擎与演讲者交互台，支持全键盘极速盲操。

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **`→` / `Space` / `PageDown`** | 下一页 | 平滑切换至下一张幻灯片，自动触发 GSAP 入场动效 |
| **`←` / `PageUp`** | 上一页 | 返回上一张幻灯片 |
| **`F`** | **原生全屏放映** | 调用浏览器原生 Fullscreen API，自动隐去翻页按钮，底部悬浮极简指示胶囊 |
| **`Esc`** | 退出全屏 / 取消编辑 | 退出当前全屏播放或取消未完成的直编焦点 |
| **`E`** | **行内文案直编** | 开启行内所见即所得修改模式，全屏所有文字均可直接点选改写 |
| **`Cmd + S` / `Ctrl + S`** | 保存文案 | 将直编修改后的文案持久化写入浏览器本地缓存 |
| **`P`** | **导出 16:9 PDF** | 调用系统原生打印面板，无损矢量化输出全部幻灯片，严格 16:9 比例无白边 |
| **`R`** | 重播入场动效 | 重新播放当前幻灯片的 GSAP 编排动效 |

---

## 导出纯净版演示文稿 (Export Clean HTML)
- 点击顶部控制栏或母色抽屉底部的 **“导出纯净 HTML”** 按钮。
- 系统会自动将您当前**直编修改后的所有文字**与**当前激活的母色变量**直接改写并烘焙进纯静态 HTML 源码中。
- 自动剔除所有控制台、抽屉与编辑脚本，生成极度轻量、零依赖的 `.html` 独立文件。
- **无论拷到任何电脑、投影仪设备或离线脱网环境下打开**，均能保持完全一致的排版、配色与 16:9 全屏演讲体验。
