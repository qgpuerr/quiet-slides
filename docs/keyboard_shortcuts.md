# Quiet Slides 交互控制与快捷键指南

Quiet Slides 内置自研 16:9 等比缩放引擎与演讲者交互台，支持全键盘极速盲操。

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **`→` / `Space` / `PageDown`** | 下一页 | 平滑切换至下一张幻灯片，自动触发 GSAP 入场动效 |
| **`←` / `PageUp`** | 上一页 | 返回上一张幻灯片 |
| **`F`** | **原生全屏放映** | 调用浏览器原生 Fullscreen API，自动隐去翻页按钮，底部悬浮极简指示胶囊 |
| **`Esc`** | 退出全屏 / 关闭弹窗 | 退出当前全屏播放、关闭快捷键指南弹窗或取消编辑焦点 |
| **`?` / `/`** | **快捷键指南** | 呼出 / 关闭极简毛玻璃快捷键指南弹窗 |
| **`E`** | **行内文案编辑** | 开启行内修改模式，所有文字均可直接点选改写 |
| **`Cmd + S` / `Ctrl + S`** | 保存文案 | 将修改后的文案持久化写入浏览器本地缓存 |
| **`P`** | **导出 16:9 PDF** | 调用系统原生打印面板，无损矢量化输出全部幻灯片，严格 16:9 比例无白边 |
| **`R`** | 重播入场动效 | 重新播放当前幻灯片的 GSAP 编排动效 |

---

## 导出 HTML (Export HTML)
- 点击顶部控制栏的 **“导出 HTML”** 按钮。
- 系统会自动将您当前**编辑修改后的所有文字**与**当前激活的配色变量**直接改写并保存进纯静态 HTML 源码中。
- 自动剔除所有控制台与抽屉，生成极度轻量、零依赖的 `.html` 独立文件。
- **无论拷到任何电脑、投影仪设备或离线脱网环境下打开**，均能保持完全一致的排版、配色与 16:9 全屏演示体验。
